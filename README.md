# ESP32 RTC Clock

DS3231 Real-Time Clock with ESP32 — set and display current time.

## Wiring
| DS3231 | ESP32 |
|--------|-------|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

## Library
Install **RTClib by Adafruit** via Arduino Library Manager.
